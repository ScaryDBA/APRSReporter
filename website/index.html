About This Project

This web page is a project to demonstrate the operations of the BridgeCom Systems Maverick transceiver. It's also a demonstration of AWS Lambda Functions, PostgreSQL running on AWS Aurora, and the PostGIS Global Information Systems extension. The whole thing was built using Claude AI.
